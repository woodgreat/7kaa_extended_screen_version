# 7kaa_hd 与官方 7kaa 的关系说明

## 官方 7kaa 的组成

官方源码包（如 `7kaa-2.15.7.tar.gz`）包含：

```
7kaa-2.15.7/
├── src/           ← C++ 源码（需要编译）
├── include/       ← 头文件
├── data/          ← 游戏资源（图片、音效、地图等）
├── configure.ac   ← 构建配置
├── Makefile.am    ← Makefile 模板
└── ...            ← 文档、脚本等
```

**官方源码里只有源码和资源，没有编译好的程序。**

玩家需要：
1. 下载源码
2. 安装依赖（SDL2、OpenAL、enet 等）
3. 运行 `./configure && make` 编译
4. 得到可执行文件 `7kaa`

## 7kaa_hd 的改动

本工程基于官方源码，添加高分辨率支持：

### 修改的文件（63 个）

核心修改：
- `ConfigAdv.h/cpp`：新增 `vga_resolution_width/height` 配置项
- `OVGA.h/cpp`：动态帧缓冲，支持任意分辨率
- `OIMGRES.h/cpp`：新增 `put_large()`（拉伸）和 `put_cropped_area()`（裁剪）
- `OINFO.h`：UI 坐标从 `VGA_WIDTH` 动态计算
- `OWORLDMT.h`：地图缩放相关

### 新增的功能

1. **任意分辨率支持**：通过配置文件设置 `vga_resolution_width` 和 `vga_resolution_height`
2. **UI 自适应**：界面元素根据分辨率动态布局
3. **图像拉伸/裁剪**：支持高清显示

## 组合方式

### 目录结构

```
游戏目录/
├── 7kaa          ← 原版可执行文件（官方编译，不动）
├── 7kaa_hd       ← 高清版可执行文件（本工程编译）
├── data/         ← 官方游戏资源（两个版本共用）
└── ...           ← 其他官方文件
```

### 运行方式

| 版本 | 命令 | 说明 |
|------|------|------|
| 原版 | `./7kaa` | 官方 800x600 分辨率 |
| 高清版 | `./7kaa_hd` | 支持高分辨率，默认 1920x1080 |

### 恢复原版

直接删除 `7kaa_hd` 文件即可，不需要其他操作。

---

## 配置文件

高清版会在 `~/.7kaa/` 目录下读取配置，可以添加：

```
vga_resolution_width=1920
vga_resolution_height=1080
```

支持的分辨率范围：800x600 到 3840x2160

---

## 编译产物说明

| 平台 | 编译产物 | 说明 |
|------|----------|------|
| Linux | `7kaa_hd` | ELF 可执行文件 |
| Windows | `7kaa_hd.exe` | PE 可执行文件 |

两个版本共用同一套 `data/` 资源，不需要额外文件。
